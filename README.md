# Survival game


Game Engine:
          Godot v4.4

# Controls:
W/A/S/D = movment
Buttons = m1




 # Gameplay:

 Defend your self from enemys

 You can buff your player by obtaining xpp for random Upgrades

This game os only supported on Pc(web edition)

If you are on mobile you can watch this demo video:
https://youtu.be/vTgmSjAkie4


# Upgrade Guide:

lifesteal = with each upgrade your getting more health on each kill

more Health = Grands you more Health.

Combat switch = switches your Combat style to a better one(trust me)

Player speed = your getting faster with each Upgrade

Damage = with each upgrade your player is making more Damage

Heal Up = gives you 20 HP
